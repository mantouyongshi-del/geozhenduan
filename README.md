## 三、 本地极速启动指引

### 1. 后端服务启动 (FastAPI)

```bash
cd backend

# 创建并激活虚拟环境 (可选)
python3 -m venv venv
source venv/bin/activate

# 安装依赖
pip install -r requirements.txt

# 配置环境变量 (首次启动请复制 .env.example)
cp .env.example .env
# 编辑 .env 填入各大模型 API Key

# 启动后端服务 (端口 8001)
uvicorn main:app --host 127.0.0.1 --port 8001 --reload
```

- 后端 API 文档：`http://127.0.0.1:8001/docs`
- 健康检查：`http://127.0.0.1:8001/health`

### 2. 前端工作台启动 (Vite + Vue 3)

```bash
cd frontend

# 安装依赖
npm install

# 启动开发热重载服务 (端口 5173)
npm run dev
```

浏览器打开 `http://127.0.0.1:5173/` 即可直接进入**企业 AI 搜索引擎可见度 · 售前全网诊断工作台**。
